# Slick Slider

**Slide. Survive. Outlast.**

A fast-paced arcade survival maze. Every move locks you in until something stops you. Slide, survive, and outlast the laser wall closing in from behind.

## About

This game was created for the [BigMode Game Jam 2026](https://itch.io/jam/bigmode-game-jam-2026). The theme was "Slick." I used sliding as a core mechanic, inspired by icy tiles from classic RPGs. Retro neon arcade aesthetics, glowing geometry, and a dark color palette are as slick as the movement. Two meanings in one.
