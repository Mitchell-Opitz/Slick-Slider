# Slick Slider

A grid-based action survival game made for a game jam.

Slide your way through an endless field of bumper blocks while a laser wall closes in from behind. The longer you survive, the harder it gets.

---

## Gameplay

- **Move** using directional input (keyboard or gamepad)
- The player slides until hitting a bumper block — Pokémon ice-sliding style
- A laser wall scrolls in from the left. Touch it and it's game over
- Difficulty increases over time, adding more obstacles and increasing scroll speed
- Obstacle colors shift with each level

---

## Controls

| Input | Action |
|---|---|
| WASD / Arrow Keys | Move |
| Gamepad Left Stick / D-Pad | Move |

---

## Features

- Procedurally generated obstacle layouts
- Increasing difficulty with hue-shifted visuals per level
- Screen shake, screen flash, and haptic feedback (gamepad)
- Jagged animated laser with proximity haptic warning
- Impact particles, trail renderer, and squash & stretch on the player
- Looping background music
- Game over screen with restart
